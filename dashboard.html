GitHub sync setup
Connected
Your data syncs automatically every time you save anything. All devices reading the same Gist file.
5-minute setup · free · you own your data
1
Go to github.com and create a free account (or sign in).
2
Go to gist.github.com → click + (New gist) → filename: dashboard.json → content: {} → set to Secret → Create.
3
Copy the Gist ID from the URL: gist.github.com/yourname/abc123...
4
Go to github.com/settings/tokens/new → Note: "Dashboard" → Expiration: No expiration → tick gist scope → Generate → copy the token.
5
Paste both below and tap Connect. Done — paste the same values on any other device.
